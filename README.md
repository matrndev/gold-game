# Idle Gold

<img width="999" height="566" alt="game screenshot" src="https://github.com/user-attachments/assets/45635a2b-965d-4246-b4a9-074c54d8552d" />

An idle-style game where you collect gold from gold mines and upgrade those mines for the gold you collected.

But there's a twist! To redeem the gold you collected, you first have to go to a Dropoff Point, which is surrounded by enemies who steal your precious gold. Click on the enemies to combat them!

> *This game was made with a massive time constraint and is still in very early development. There should be no bugs, but I apologize for the lack of visual prettiness...*

## Hotkeys
**`W, A, S, D`** -- movement

**`LMB`** -- attacking enemies


## AI Disclaimer
AI (LLMs) was used during the creation of this project.

I used GitHub Copilot Chat to help me to help me better understand GDscript and Godot.

I sometimes let it write me code snippets, which I never blindly copy directly as outputted by the model, but rather I make sure I understand it and I often adapt or rewrite it to better suit my needs. 

AI code completion was not used, since it isn't available in the Godot editor.
